## 游戏说明

一共12关。每关将所有牌分成指定组数，每组凑成10；选中数字总和为10时自动标组，点已分组的任意一张即可撤销整组。完成全部卡片分组后过关。最后一关完成有明确的通关提示。圆点卡与海洋卡分别可选，两个主题各混合三种数量排列方式，采用教研提供的六张卡面素材。
