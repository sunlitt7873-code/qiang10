# 抢10 · 动物版

静态网站，GitHub Pages 从 `main` 分支根目录发布。当前版本 v0.9。

## 游戏规则

- 每题六张卡，点击整张牌；再点已选牌可以取消。
- 所选牌的两种动物分别相加，任一种超过10时拒绝新牌。
- 没有超过10，且至少一种动物恰好等于10时，立即计一组并换题。
- 不显示累计数量、不弹成功提示。一局60秒，未完成题目不计分。
- 两套固定卡牌交替使用，每次打乱位置；当前不是随机生成新牌。

## v0.9 修复

旧代码把两套石墨图片的链接接反：小丑鱼画面使用海龟数据，反过来也一样。例如画面上的小丑鱼4+1+5，旧后台会算成6+1+5=12。另外，浏览器可能收到石墨的防盗链提示图。

现在用用户提供的两张原图逐张核对，将12张卡提取为独立 WebP 文件，图片与数值在一个卡片对象中绑定。所有素材随仓库发布；素材加载完成才允许开始。首页是唯一游戏实现，旧 `test-v08.html` 自动跳回首页并保留调试参数。

`game-v09.js` 管理游戏状态与判定，`app-v09.js` 负责显示与交互。成功时同步换题，点击时也检查截止时间，防止后台标签页延迟计时导致超时得分。

## 验证

运行 `node --test tests/game.test.cjs`。包括用户反馈的两组组合、所有126个非空子集及合法获胜组合的不同点击顺序、取消/拒绝、60秒边界、重开及旧入口重定向。

开发核对时可加 `?debug=1` 显示累计数量；正常游戏不显示。
